# Python-Projects
A brief collection of my previous Python projects.

My Bioprogramming Final Assessment Project was completed in my second year of my studies. The code written will open a FASTA file, read its contents and write a new file with only the descriptor line and DNA content. The code then creates a complement sequence based on the DNA bases in the FASTA sequence, translates the complement sequence into its corresponding amino acids and identifies Open Reading Frames in the sequence.

My Computer Science Leaving Certificate Project was completed between December of 2022 and March of 2023. The task assigned was to design a Python program that could model, simulate and analyse data from a game. I decided to code Hangman, enabling single and multi-player optionality. I also coded for the simulation of hundreds of rounds of Hangman, using bespoke guessing strategies to determine which strategy gave the greatest advantage. The data from the simulation was saved and using data analysis libraries I performed data analysis and discovered the best and worst strategies and trends.
